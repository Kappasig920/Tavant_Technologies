# Tavant Technologies - NotebookLM URL Repository

## 🎯 Purpose

This repository serves as a centralized hub for all URL addresses that have been indexed into NotebookLM, enabling ChatGPT to access and utilize comprehensive contextual information about Tavant Technologies for interview preparation and general knowledge enhancement.

## 📋 Overview

This repository is designed to:
- House all URLs indexed into NotebookLM for easy reference
- Provide structured access to company information, technical resources, and industry insights
- Enable ChatGPT to deliver more contextually aware and accurate responses
- Support interview preparation with organized, categorized resources

## 🗂️ Repository Structure

```
Tavant_Technologies/
├── README.md                 # This file - documentation and usage guide
├── urls.json                 # Main structured URL database
├── url-template.md          # Template for adding new URLs
└── .gitignore               # Git ignore configuration
```

## 📖 How to Use This Repository

### For ChatGPT Integration

This repository is designed to be connected to ChatGPT to improve contextual awareness. The `urls.json` file contains all indexed URLs with metadata including:
- **Title**: Descriptive name of the resource
- **URL**: Direct link to the content
- **Description**: Brief summary of what the resource contains
- **Indexed in NotebookLM**: Flag indicating if the content is indexed
- **Relevance**: Priority level (high/medium/low)
- **Tags**: Keywords for categorization and search

### For Human Users

1. **Browse URLs**: Check `urls.json` for all available resources organized by category
2. **Add New URLs**: Use the template in `url-template.md` to add new resources
3. **Update Information**: Keep URLs current and accurate for best results

## 📚 URL Categories

The repository organizes URLs into the following categories:

1. **Company Information** - Official company websites, about pages, mission/vision statements
2. **Technical Resources** - Technical blogs, documentation, technology stack information
3. **Industry Insights** - Industry-specific solutions, market trends, domain expertise
4. **Interview Preparation** - Specific resources for interview readiness

## 🔄 Adding New URLs

To add a new URL to the repository:

1. Open `urls.json`
2. Navigate to the appropriate category
3. Add a new URL object following this structure:

```json
{
  "title": "Resource Title",
  "url": "https://example.com",
  "description": "Brief description of the resource",
  "indexed_in_notebooklm": true,
  "relevance": "high",
  "tags": ["tag1", "tag2", "tag3"]
}
```

4. Commit and push your changes
